## Positionnement

- Pilates & Barre en visio, coach Alejandra, femmes, 39€/mois groupe. Marché FR (primaire), ES (secondaire).
- Promesse : « être vue, la correction en direct, ne plus lâcher seule, tenir dans la durée. » C’est l’angle, pas les features.
- Aimant unique = le **quiz de personnalité gratuit** (aucune salle ne peut le copier).

## Philosophie funnel (règle d’or)

- On répare les fuites **AVANT** de scaler le trafic. Payer pour remplir un seau percé = brûler du budget.
- Parcours cible : Ad/organique → quiz gratuit → email capturé → nurture → essai 7j → abonnement 39€ → rétention.
- La plupart dépensent 90 % sur le haut de funnel et laissent fuir le milieu/bas. Nous : **bas de funnel d’abord**.

## Règles conversation (workflows / concierge)

- **NE JAMAIS** répondre à un refus par une demande. Le follow-gate ne part **QUE** sur une vraie demande d’info/essai.
- Toujours gérer le **soft-no** : refus poli / « déjà inscrite ailleurs » / « pas pour moi » → clore poliment + tag `soft_decline` + **ZÉRO** relance.
- Respecter le refus et l’agacement même sans mot « stop ».
- Reconnaître une cliente déjà payante (CRM synchronisé avec Stripe) → **jamais** lui pitcher l’essai.
- Ne jamais empiler email + WhatsApp + DM sur la même personne.

## Règles ads

- Meta d’abord (canal n°1 lead gen fitness), un canal bien avant d’éparpiller ; multi-canal ensuite.
- Format : Lead Ads (formulaire natif) OU trafic vers le quiz. Offre à faible friction = le quiz gratuit.
- Copy = bénéfice/émotion, pas feature. Créatives = UGC/vraies vidéos (Reels, adhérentes) > léché.
- 3 campagnes : froid (découverte quiz) / warm (retargeting visiteuses) / hot (retargeting essai non fini).
- Compliance santé : pas d’avant/après garantis, pas de promesse médicale.
- Budget test validé : ~15–30 €/jour sur Meta pour obtenir des données ; scaler les gagnantes.
- API Meta Ads : préparée, mais **AUCUNE** dépense sans confirmation humaine explicite.

## Honnêteté des données (non négociable)

- Jamais de faux vert dans une checklist. Jamais un proxy affiché comme un chiffre réel : étiqueter « estimation » ou recalculer.
- Ne jamais attribuer au système une conversion qu’il n’a pas produite.
