# FitMangas — Marché femmes (FR / MX)

> Référence pour l’onglet **Marché** et le Plan d’action. Positionnement **large** : ne pas s’enfermer dans la niche stricte « Pilates & Barre online » — le produit réel = **ne pas être seule** + correction + rendez-vous collectifs.  
> Sources datées en bas. Distinguer **FR** et **Mexique** (codes culturels différents).

## Ce que veulent les femmes (universel wellness / midlife)

| Besoin | Formulation produit | À éviter |
|---|---|---|
| **Constance douce** | Rituel fixe, pas « motivation » | Discipline punitive |
| **Non-jugement** | Espace safe, trash-talk industrie seulement | Corps / âge / poids |
| **Être vue** | Correction en direct, coach qui te regarde | Vidéos YouTube anonymes |
| **Mind-body** | Respiration, dos, stress, énergie — pas que « abdos » | Pure esthétique |
| **Pour la vie, pas pour le look** | Longévité, mobilité, post-partum / 45+ | Transformation 6 semaines |
| **Convenance at-home** | Visio depuis chez soi, matériel minimal | « Viens en studio » comme seul argument |

→ La cliente ne paie pas pour du Pilates gratuit disponible partout : elle paie pour le **rendez-vous** + la **correction** + le **fait d’être vue**.

## Positionnement : message large vs niche

**Trop niche (à élargir en pub froide)**  
« Studio Pilates & Barre en ligne pour expertes » → volume bas, auto-exclusion.

**Message large (recommandé froid)**  
« Tu as déjà essayé seule et tu as lâché ? Rejoins des cours collectifs à horaires fixes, avec une coach qui te corrige en direct. »

Pilates / Barre restent le **support**, pas toute la promesse. Quiz (connaissance de soi) = aimant hors concurrents salles.

## Bloc FRANCE (marché primaire)

### Codes culturels
- Direct, honnête, anti-Bullshit marketing ; méfiance « miracle ».
- Prix : **39 €** groupe affirmé ; essai 7 j avec carte = acquis.
- Langue : FR d’abord ; tutoiement marque OK ; pas de « Mangitas ».
- Douleurs concrètes : dos bureau, post-partum, 45+, stress, sommeil.
- Concurrence : YouTube gratuit, Decathlon, salles — différencier par **live + communauté**.

### Angles pub froide FR (prioritaires)
1. Dos / 15h / bureau  
2. Essai 7 j sans pression  
3. Correction en direct (vs replay seul)  
4. « Envoie ça à une copine » (confiance)  
5. Quiz → lead soft

### Angles à doser
- « Pilates technique » pur → secondaire  
- Présentiel Nantes → warm / local seulement

## Bloc MEXIQUE (marché secondaire)

### Codes culturels
- Relationnel, chaleur, communauté familiale ; WhatsApp fort.
- ES : tutoiement / « tú » naturel ; éviter calques FR littéraux.
- Prix : adapter messaging (pouvoir d’achat, confiance) — ne pas coller 39 € FR sans contexte.
- Bien-être + discipline douce ; image coach accessible.
- Canaux : IG / WhatsApp prioritaires ; Facebook encore utile.

### Angles pub froide MX (prioritaires)
1. Comunidad + no estás sola  
2. Corrección en vivo  
3. En casa, cuando te conviene  
4. Prueba / essai expliqué clairement  
5. Quiz ES si funnel ES prêt

### À éviter MX
- Ton froid « corporate FR »  
- Juger le corps / « bajar de peso » comme promesse centrale  
- Ignorer WhatsApp comme filet

## Conclusion — comment te vendre par la pub

1. **Promesse large** : solitude / constance / être vue — Pilates = véhicule.  
2. **Créatives** : UGC 15–30 s, hook 3 s, PAS ou Hook-Problème-Solution-Preuve (`ADS_EXPERTISE.md`).  
3. **CTA** : essai 7 j ou quiz — anti-risque.  
4. **FR d’abord** en volume ; **MX** = créatives ES dédiées, pas simple traduction.  
5. Croiser avec **démographie Meta réelle** (âge / genre / pays) : qui te suit vs qui tu pourrais toucher — ne pas cibler uniquement « fans Pilates ».
